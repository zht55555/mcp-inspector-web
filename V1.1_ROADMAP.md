# V1.1 Roadmap

1. Replace mock tool execution with real MCP SDK integration.
2. Add session persistence, replay, and saved tool argument templates.
3. Introduce richer execution metrics: total calls, success rate, average duration.
4. Add server-side restart / recovery actions for bridge crash scenarios.
5. Improve schema coverage for nested object arrays and more advanced JSON Schema patterns.
6. Add automated smoke tests for connection, tools list, call flow, and SSE subscription.
7. Support multi-session workflows and environment profiles.
